本轮保留 **0.1.0**，重点检查“拿到的画面是否对得上时间、跨章解释是否接得起来、失败后是否漏读、最终讲解是否好懂”。修复了 16 类问题，补充原图课件与图文导出；没有新增模型服务或运行依赖。

## 理解与讲解

知识检索现在能沿已保存的关系带回中间步骤。例如“量化为什么影响吞吐量”，可同时取回“量化→显存占用→批大小→吞吐量”。这是引用已有笔记的路径发现；关系本身由读过材料的 AI 保存，检索不凭词语共现创建因果。

Markdown 导出包含章节标题、解释、事实、关系及引用过的原图。离线 HTML 增加逐步图片：本地图片经校验、缩放和去除元数据后内嵌，重复图片只保存一份，图注保留原片时间链接。页面可离线切换步骤、查看状态，并按需使用已有 softmax 交互演算。

写作指南采用一个连续输入串联过程，图前告诉读者看哪里，图后解释变化。独立 agent 用 B站 KV Cache 视频实测，实际打开 7 张原帧，生成含 3 张原图的讲解和 5 步 HTML。第一次输出仍混入“缺少数值／日志，因此不能……”的无关段落；据此精修指南，再由原作者生成副本。最终沿“床前明→月→光”解释已有状态、新增 Q/K/V、缓存追加和下一字预测，保留完整 Q 示意与增量计算的区别，将内部核验记录移出正文。

HTML 的导航、键盘、状态和图片切换通过离线 DOM 检查，3 张内嵌图已实际打开。浏览器策略拒绝本地文件，本轮没有验收真实浏览器布局和窄屏排版。私有讲解、原图及原版评审保存在 `.vidlens/review-2026-11-06/`，不进入版本库。

## 清理与仍需推进的工作

已删除 `EvidenceReader.read` 中不可达的旧整片采样分支，整片入口统一走章节流程。导出删除逐章重新读取所有证据的重复工作，改用一次快照和索引。保留确实验证失败恢复、时间归属和数据完整性的测试，也保留旧安装命令的兼容入口。

同一份神经网络笔记，改动前 3 次本地导出耗时为 30.68／21.90／21.15ms，改动后为 9.71／4.65／4.56ms；新输出还增加了关系和 13 张原图引用。这是少量缓存观察，记录用于检查重复工作，没有据此给出稳定加速倍数。

| 优先级 | 剩余问题 | 后续验收方式 |
|---|---|---|
| 高 | 中文 ASR 仍会误识别 Q/K/V、token、矩阵等技术词；已有数据发生过的历史覆盖不能靠 ID 修复自动找回 | 用人工标注的短课集比较术语、数字和公式准确率，再决定 ASR 后端；关键符号继续结合画面核对 |
| 高 | 低清差异检测不是语义理解；动画产生大量候选，缩图也可能抹掉细字 | 在保留全部候选的前提下评估分层导航、清晰度与信息增量排序，测量真实漏检率 |
| 中 | `inspect` 会附带已有知识摘要，独立验证者可能被旧结论带入 | 现可用原始区间和画面核验；评估显式原始证据模式与笔记纠错体验 |
| 中 | 没有跨项目同题的理解正确率、原图使用质量和端到端费用评测 | 建立人工审阅的问题集，分别测来源定位、解释正确性和实际客户端开销 |
| 中 | HTML 的真实浏览器布局与窄屏操作尚未验收 | 在允许本地文件的浏览器环境做视觉和操作检查 |
